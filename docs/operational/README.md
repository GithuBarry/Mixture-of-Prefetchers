# Operational Docs

This subdirectory holds implementation-heavy and workflow-heavy documents.

Use these files when you need exact reproduction steps, schema definitions,
search boundaries, historical logs, or agent instructions.

- `experiment_setup.md`: official trace suite, split, run modes, and command examples
- `environment.md`: toolchain, trace handling, artifact flow, and regeneration order
- `dataset_schema.md`: exact meaning of `data/processed/runs.csv`
- `research_log.md`: chronological engineering and experiment log
- `transparency_log.md`: decision log and confidence notes
- `trace_inventory.md`: candidate trace pool and source mapping
- `stage2_memo.md`: frozen Stage 2 search contract
- `mop_stage1_instruction.md`: Stage 1 charter for agents
- `mop_stage2_instruction.md`: Stage 2 charter for agents
